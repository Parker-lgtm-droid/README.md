# GitHub Notes

## What I Learned
- GitHub stores projects in repositories.
- Commits record saved changes with messages.
- Push uploads local changes to the remote repository.
- Branches help keep work isolated before merging.
- Pull requests let teammates review changes before they are merged.

## Branch Practice
1. Create a branch
2. Edit files
3. Commit changes
4. Open a pull request
5. Review changes
6. Merge into main

## Key Reminder
Version control helps protect work and makes collaboration easier.
