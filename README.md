## Key Concepts Learned

### GitHub
- Repositories store project files and history
- Commits save changes with descriptive messages
- Push uploads work to the remote repository
- Branches allow safe experimentation before merging
- Pull requests help review and approve changes

### Termux and Linux Basics
- `pwd` prints the working directory
- `ls` lists files and folders
- `cd` changes directories
- `mkdir` creates a directory
- `nano` opens a text editor
- `cat` reads file content
- `echo` prints text to the terminal

### Grok Bot
- Useful for debugging code and explaining concepts
- Helpful for learning new libraries and tools
- Can support rapid experimentation and troubleshooting
